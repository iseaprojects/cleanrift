# Contributing to CleanRift

Thanks for helping. CleanRift is a Windows desktop application written in C#
with WinForms on .NET 9.

## Build

Requirements:

- Windows 10 or Windows 11, 64-bit
- .NET 9 SDK
- Optional: Inno Setup 6, to build the installer

```powershell
dotnet build CleanRift.sln -c Release
```

Portable package and installer:

```powershell
.\build.ps1
```

Language XML files are generated from `languages/english.csv` and
`languages/spanish.csv`:

```powershell
.\tools\Build-Languages.ps1
```

The application icon is generated from code:

```powershell
.\tools\Build-BrandAssets.ps1
```

## Project rules

- Do not add third-party icons, language files, or copied application code.
  All UI artwork is generated by `AppIcons.cs` and `Build-BrandAssets.ps1`.
- Keep product names, data paths, mutexes, scheduled tasks and AppIDs under the
  CleanRift namespace. Do not reference another uninstaller's files or profile.
- Removal operations are destructive. Always test them on a disposable VM.
- Keep the UI usable in light and dark mode. Test dialogs with both themes.
- When adding UI text, add it to both CSV files and run the generator.
- Prefer small, focused commits with a clear message.

## Commit messages

Use the imperative mood, for example:

```
Add startup task cleanup to the uninstaller
Fix dark theme for the language selector
Update Spanish translation for the removal wizard
```

## Security

Do not open public issues for vulnerabilities. See `SECURITY.md`.
